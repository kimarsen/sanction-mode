**Sanction Mode** — игровой режим для Minecraft Forge 1.12.2. Игрок летает и не получает урон, как в креативе, но ломает блоки, тратит инструменты и голодает как в выживании. Предметы из каталога выдаются безлимитно только после одобрения оператора.

**Скачать мод можно в разделе Releases: [`sanctionmode-1.0.0.jar`](https://github.com/kimarsen/sanction-mode/releases/download/v1.0.0/sanctionmode-1.0.0.jar).**

## ✨ Что умеет режим

* **Полёт** включается двойным прыжком, как в креативе.
* **Неуязвимость** закрывает обычный урон. Пустота по-прежнему убивает, как в креативе.
* **Ломание блоков** идёт с обычной скоростью выживания: нужны инструменты, блоки выпадают, прочность тратится.
* **Каталог предметов** показывает блоки и предметы модпака. Без разрешения оператора клик только отправляет запрос.
* **Разрешение на 1 час.** Повторный клик оператора добавляет ещё один час к оставшемуся времени. Пока таймер идёт, любой игрок в этом режиме берёт предмет без ограничения количества.
* Разрешения сохраняются в мире и не сбрасываются при выходе.

## 🎮 Команды

Команды доступны оператору, уровень прав как у `/gamemode`.

| Команда | Действие |
| :--- | :--- |
| `/gamemode 4` | Включить режим себе |
| `/gamemode 4 Имя` | Включить режим игроку |
| `/gamemode 0` | Выключить режим и вернуть выживание. Так же работают `1`, `2` и `3` |
| `/sanction` | Открыть интерфейс одобрения |
| `/sanction on Имя` | Включить режим |
| `/sanction off Имя` | Выключить режим |

## 📦 Каталог игрока

| Действие | Результат |
| :--- | :--- |
| **G** или кнопка «Каталог» в инвентаре | Открыть каталог |
| **ЛКМ** по предмету с зелёной рамкой | Положить полный стак в инвентарь |
| **ЛКМ** по предмету без разрешения | Отправить запрос оператору |
| **Колёсико мыши** по блоку в мире | Запросить или взять этот блок |

## 🛡️ Интерфейс оператора

Открывается клавишей **K** или командой `/sanction`.

| Действие | Результат |
| :--- | :--- |
| **ЛКМ** | Разрешить предмет на 1 час. Повторный клик добавляет ещё час |
| **ПКМ** | Сразу запретить предмет |
| **Вкладка с бумагой** | Очередь запросов. В подсказке видно, кто просил |

Зелёная рамка означает, что предмет уже разрешён. Жёлтая рамка означает, что его кто-то запросил.

---

## 🕹️ Клавиши

Клавиши меняются в настройках управления, раздел «Режим допуска».

| Клавиша | Действие |
| :--- | :--- |
| **G** | Каталог предметов |
| **K** | Одобрение предметов |
| **H** | Показать или скрыть надпись «Допуск» |

Надпись скрыта, пока игрок сам её не включит. При выходе из режима она гаснет.

## 📥 Установка

1. Установите **Minecraft Forge 1.12.2**, сборка `14.23.5.2847` или новее. Проверено на `14.23.5.2864`.
2. Нужна **Java 8**.
3. Скачайте [`sanctionmode-1.0.0.jar`](https://github.com/kimarsen/sanction-mode/releases/download/v1.0.0/sanctionmode-1.0.0.jar).
4. Положите один и тот же файл в `mods` клиента и в `mods` сервера.
5. Перезапустите игру и сервер.

## 🔧 Сборка из исходников

```bat
gradlew build
```

## 🇬🇧 English

Sanction Mode is a Forge 1.12.2 gamemode. Players fly and ignore damage like creative mode, while block breaking, tool durability and hunger stay on survival rules. Creative catalog items can be taken without limit only after an operator approves them. Each approval lasts one hour, and another click adds one more hour.

| Command | Effect |
| :--- | :--- |
| `/gamemode 4 [player]` | Enable the mode |
| `/sanction` | Open the approval screen |
| `G` / `K` / `H` | Catalog, approval screen, toggle the on-screen label |

Put the same jar on the client and the dedicated server. Forge `14.23.5.2864` and Java 8 are the tested target.
